# dementia panel

## English

The React web interface lets administrators manage users, subscriptions, and nodes. Its Docker image serves the interface over HTTPS and forwards API requests to the backend. [Full installation guide](https://github.com/dementia-panel#english)

## Русский

Веб-интерфейс на React позволяет администратору управлять пользователями, подписками и нодами. Docker-образ отдаёт интерфейс по HTTPS и передаёт запросы API в backend. [Полная инструкция по установке](https://github.com/dementia-panel#русский)
