# Application marks

The application marks identify the corresponding official VPN clients. Their original path geometry is preserved; SVG masks render them using the surrounding interface color.

- AmneziaVPN: monochrome application mark from [amnezia-vpn/amnezia-client](https://github.com/amnezia-vpn/amnezia-client/blob/762f61cea330519fea4a9a4a34fae3b80a3b151e/client/images/AppIcon.icon/Assets/02-mark-mono.svg).
- AmneziaWG: application vector from [amnezia-vpn/amneziawg-android](https://github.com/amnezia-vpn/amneziawg-android/blob/master/ui/src/main/res/drawable/ic_icon.xml), converted from Android VectorDrawable to SVG without changing the path.
